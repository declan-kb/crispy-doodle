This app needs a free Firebase project so the team list can sync across everyone's devices. Open team-list-store.js, find the firebaseConfig object near the top, and paste in your project's config values. See the setup steps in that file's header comment for how to get them.

This page needs to be served, not opened directly

The app is split across style.css and team-list-store.js, and browsers refuse to load those from a file:// or data: page — so nothing renders.

Use the GitHub Pages URL, or run this in the project folder and open http://localhost:8000: 

python3 -m http.server 8000
